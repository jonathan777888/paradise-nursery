# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux shopping cart application for an online plant store.

This project allows users to browse houseplants, view plant names, images, descriptions and prices, add plants to a shopping cart, manage item quantities, remove items, and view the total cart cost.

## Features

- Landing page for Paradise Nursery
- Product listing page with plant categories
- At least six unique houseplants
- Add to cart buttons
- Redux cart state management
- Dynamic cart icon showing total number of items
- Cart page with quantity controls
- Remove items from cart
- Total cost calculation
- Checkout button showing “Coming Soon”
- Continue shopping button
